# Algorithms_2_practice

1.Вывод пользователей в порядке рейтинга.
АЛГОРИТМ: Bucket Sort
СЛОЖНОСТЬ:
    Время: O(N + K), где N - количество элементов,
    K - диапазон значений (в худшем случае O(N^2))
    Память: O(N + K)

    ===Первый тест===
    [0.72, 0.18, 0.5, 0.03]
    [0.03, 0.18, 0.5, 0.72]


    ===Второй тест===
    [0.66, 0.66, 0.1]
    [0.1, 0.66, 0.66]

2. Сервер записал коды ошибок от 0 до 999. Нужно упорядочить несколько миллионов записей по коду,
не создавая структуру на все возможные 32-битные числа.
АЛГОРИТМ: Counting Sort
СЛОЖНОСТЬ:
    Время: O(N + K), где N - количество элементов,
        K - разрядность
    Память: O(N + K)

    ===Первый тест===
    [404, 0, 500, 404]
    [0, 404, 404, 500]


    ===Второй тест===
    [999, 1, 1, 12]
    [1, 1, 12, 999]

2. Штрихкод представлен как 12-значное неотрицательное число. Требуется сортировать записи по коду,
не создавая массив счётчиков размера диапазона кодов.
АЛГОРИТМ: Radix Sort
СЛОЖНОСТЬ:
    Время: O(N * d), где N - количество элементов,
        d - разрядность
    Память: O(N + K)

    ===Первый тест===
    [123456789012, 12, 900000000000]
    [12, 123456789012, 900000000000]

    ===Второй тест===
    [111111111111, 101010101010]
    [101010101010, 111111111111]
